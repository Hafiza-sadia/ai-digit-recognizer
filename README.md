🧠 AI Digit Recognizer

AI Digit Recognizer is a web-based application that allows users to recognize handwritten digits (0–9) using Artificial Intelligence.  
This project is designed to demonstrate how machine learning models can be integrated with a simple front-end interface to solve real-world problems such as digit recognition.

The application provides a clean and user-friendly interface where users can navigate between different pages, recognize digits, view recognition history, and learn more about the project.

---

📌 Project Objectives

The main objectives of this project are:

- To build a simple and interactive web interface for digit recognition  
- To demonstrate the working of an AI-based handwritten digit recognition system  
- To help beginners understand how front-end and AI systems can work together  
- To provide an educational project for learning HTML, CSS, JavaScript, and basic AI integration  

---

🚀 Features

- 🎯 Recognizes handwritten digits from 0 to 9  
- 🖌️ User-friendly and responsive interface  
- 🌐 Multiple pages (Home, Recognize, History, About)  
- 🕒 Stores and displays recognition history  
- ⚡ Fast and efficient predictions  
- 🎨 Attractive UI with background image and animations  

---

🛠️ Technologies Used

 Front-End:
- HTML5 – Structure of the web pages  
- CSS3 – Styling, layout, animations, and background effects  
- JavaScript – Handling user interactions and logic  

 (Optional / Future Scope – Back-End & AI):
- Python  
- TensorFlow / Keras  
- Trained Machine Learning Model (MNIST dataset)
